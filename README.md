# 📦 Inventory Management System Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Inventory Management Dashboard developed using Tableau. The dashboard provides comprehensive insights into sales, revenue, profit, warehouse operations, product performance, and customer behavior. It enables businesses to monitor key performance indicators and make data-driven decisions to improve operational efficiency and profitability.

---

## 🎯 Objectives

The primary objectives of this project are:

1. Analyze overall revenue and profit performance.
2. Track monthly sales trends and business growth.
3. Evaluate regional and warehouse performance.
4. Identify top-performing products and product categories.
5. Monitor customer purchasing behavior and business risks.
6. Support strategic decision-making through visual analytics.

---

## 🛠️ Tools & Technologies

* Microsoft Excel (Data Cleaning & Preparation)
* Tableau (Dashboard Development & Visualization)
